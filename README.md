## Additional Project Material
A supplementary ZIP archive is provided together with the project repository. It contains:

- **Bibliographic and reference sources** used throughout the development of the project.
- **Complete simulation results**, including MATLAB figures, command-window outputs, and intermediate numerical results.
- **MATLAB functions and auxiliary routines** required by the main script `main_sc_project.m`.

### Computational Requirements
The complete simulation is computationally intensive. Running `main_sc_project.m` from start to finish may require approximately **12 hours**, depending on the available hardware.

The long execution time is mainly associated with the iterative convergence procedures used throughout the coupled electromagnetic and thermo-hydraulic calculations, particularly during the numerical solution of the most computationally demanding parts of the model.

For this reason, the ZIP archive also includes the previously generated simulation outputs, allowing the main results and figures to be inspected without having to repeat the complete calculation.
